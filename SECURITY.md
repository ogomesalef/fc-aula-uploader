# Segurança

- Use **suas** credenciais de admin do portal. Nunca compartilhe `.env` ou arquivos de sessão.
- Sessões ficam em `~/.config/aula-uploader/` (permissão restrita). Remova com `aula-uploader logout`.
- Só os hosts oficiais configurados no código são aceitos.
- Logs mascaram URLs assinadas e possíveis Access Key IDs.
- Esta CLI automatiza ações que você já pode fazer no admin; quem tiver suas credenciais terá o mesmo poder.

Para reportar um problema de segurança neste repositório, abra um issue privado ou contate o mantenedor.
